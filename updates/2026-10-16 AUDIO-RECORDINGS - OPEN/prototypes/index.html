Decisions for you

The prototypes make each of these tangible — pick, and I lock the design (P2) before any app code.

#1 · Audio inside a gallery

A bar has no aspect ratio, so it fights the justified image strip. See prototype 03.

Lean: Option C — a waveform-card tile that opens the canonical bar in a “Now playing” dock. Obeys the tile math and keeps “one bar everywhere.”

#2 · Transcript: Split View vs full overlay

Desktop default is the resizable split (new to the shell). Narrow windows fall back to a full overlay. See prototype 04.

Lean: split on desktop, overlay only when too narrow / on phone.

#3 · How recording starts

Capture starts as an inline bar in the note, vs a dedicated recorder that drops a bar on stop. See prototype 02.

Lean: inline bar (one component, in-flow). And: does recording / “Create transcript” ship in this update, or wait for the transcription step?

#4 · Showing two speakers

Diarization by weight/tone only (protects one-accent), vs an optional faint left speaker-rail (border weight, no new hue). Toggle inside prototype 04.

Lean: weight/tone, rail optional.

#5 · Polished vs raw transcript

The schema carries polished: true. Always show polished, or offer a raw/polished toggle in the dock? Toggle inside prototype 04.

Lean: show polished, raw as a later toggle.

Smaller calls I’ll fold in

Record/stop control is accent, not red (one-accent rule) — override if you want the familiar red. On the Basin, Space both pins a peek and plays a focused bar — needs a clear owner. Accio ranks transcript hits at body-tier so rich recordings surface.

Underneath: the transcript sidecar schema is locked (media/<note>/<media>.mp3.transcript.json, word + segment timings + speakers) so the upcoming transcription step has a fixed target. Search folds transcript text into the note’s body index (no SQLite). Engine note: the reference word-sync uses a flat binary search that mis-highlights where diarized speakers overlap — prototype 04 fixes it via segment-aware sync; that fix gets folded into the engine at build time.
