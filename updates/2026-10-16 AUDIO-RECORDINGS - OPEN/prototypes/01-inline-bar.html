The inline audio bar — in a note

The canonical surface. A recording is media: it sits in the writing flow exactly like an image block, with a caption slot beneath it. One calm bar, one accent, flat at rest, a faint halo only while it plays. Built on _kit.css + _audio.js against the real 19-minute call. Flip the theme (top-right).

1 · A note with a recording

Fully interactive. Press play (or focus the waveform and hit Space), scrub by dragging, hover for the preview bubble, open the ⋯ menu. Starting it pauses every other bar on the page.

2 · Every state, in the note

Each state as a small excerpt so you see how the bar reads inside prose. Live bars play the real audio; visual bars freeze a moment so the look is always inspectable — the live bars reproduce those same looks as you drive them (play → halo, drag → scrubline).

Menu order: Download recording, then the transcript action (Create transcript when absent · Open transcript when present · disabled Transcribing… mid-run), then Replace… / Remove below a separator — matching the image MediaBlock menu.
