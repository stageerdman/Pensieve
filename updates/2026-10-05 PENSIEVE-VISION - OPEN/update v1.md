# Update v1 — PENSIEVE-VISION (magical UX concepts)

Status: **Exploration delivered.** A design-vision spike, not shipping work.

## Goal
Explore what Pensieve could look and feel like — the UI and the UX of capturing and
storing memories — if the app truly embraced the Pensieve from Harry Potter. Owner
asked for a team of UX experts to produce interactive `.html` concepts.

## What was done
A team of four UX/visual concept designers ran in parallel, each exploring a distinct
direction and producing one self-contained, offline, interactive HTML mockup (inline
CSS/JS, all visuals via CSS/SVG/canvas, no external assets):

- `concepts/01-the-basin.html` — **The Basin.** Literal immersive Pensieve: a stone
  chamber + a live canvas pool; pour thoughts in as spiralling wisps, time-as-depth,
  dive-in immersive read, rune category filters.
- `concepts/02-strands-and-vials.html` — **Strands & Vials.** A memory cabinet of
  labelled crystal vials on category shelves; capture coils a strand into a vial;
  uncork → unspool → read. Live search/filter.
- `concepts/03-constellation.html` — **The Memory Constellation.** A drift-through
  star-field; note-links are glowing threads; revisited memories shine brightest;
  capture births a new star; era depth-of-field dial.
- `concepts/04-everyday-pensieve.html` — **Everyday Pensieve.** The pragmatic one:
  fast, calm daily app with Pensieve soul as atmosphere — pour-a-thought bar,
  shimmering memory stream, AI coach "a memory stirs", focus dive reader.
- `concepts/index.html` — a gallery landing linking to all four.

## How to view
Open `concepts/index.html` (double-click or `open`), then click into each concept.
All are file://-friendly, offline, no server needed.

## Notes
These are **vision/mood** explorations to pull ideas from — not the shipping UI. The
real app stays lightweight, local-first, and content-first (VISION.md / design.md).
Candidate ideas to harvest: the "pour a thought" capture ritual, time-as-depth,
revisit/coach resurfacing, note-links as visible threads, a focus "dive" read mode.
