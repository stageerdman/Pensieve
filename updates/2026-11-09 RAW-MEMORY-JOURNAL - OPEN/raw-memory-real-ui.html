Raw Memory — built from the real phone UI (v2)

Every panel below links the app's actual stylesheets (tokens.css, wand.css, dock.css, spellmenu.css) and reuses the actual component markup/classes — the reel card, the dock, the spell ring, the photo-collection board, the confirm sheet. No fake phone bezel; each box is just the content area at real phone width. One simplification: the reel's scroll-fisheye "glass" loupe isn't wired up — orthogonal to the Raw Memory question.

Changed from v1, per review: (1) Scene B is now ONE continuous camera session — tap once, shoot every page back-to-back, thumbnails pile up live underneath, never leaving the viewfinder (the old "Add page" button + native-handoff model is gone — see wiki.md for why that model structurally couldn't give a multi-shot session, and why this needs a real new camera component to build). (2) Scene D's "Delete whole batch" is now a Conditional spell-ring action (Dock → gold button → ring), not a flat button, matching every other context in the app. (3) Scene C dropped the flask entirely for the Raw Memory card — not a muted one, which still read as a normal categorized memory. Desktop's AI split-by-date requirement is logged as a Phase 3/5 data- model decision in wiki.md; it doesn't change anything on the phone side shown here.
