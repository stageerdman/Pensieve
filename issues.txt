      28s chunks) + Parakeet TDT v3 (fast). Python/MLX engine the Rust shell spawns; emits the
      locked Transcript schema w/ word timings. Engine bundled at Contents/Resources/engine/.
- [x] Rust `transcribe_audio` streams `transcribe-progress`; child PATH includes /opt/homebrew/bin
      (a Finder-launched .app has a minimal PATH → ffmpeg/claude not found → silent failure).
- [x] Sync popup → full-height right DRAWER w/ a Process queue (global Run/Pause + 1/→ mode,

- [x] Parakeet sub-word tokens grouped back into whole words (was letter-by-letter in the reader).
- [x] Transcription failures now show the reason on HOVER over the red error icon (2026-10-19):
      cleanEngineError strips JSON-progress/tqdm noise from the Rust stderr tail and keeps the
      real Python exception; threaded ProcessItem.errorMsg → ProcessRow tooltip. NB diagnosis:
      the engine itself works end-to-end on the 75-min "How to achieve Understanding" tape
      (parakeet ~3 min/953 segs; czech-whisper is just SLOW — ~101s per 60s of audio, so the
      Czech default on a 75-min file is ~2 h + polish). Logger is in-memory only, so a past
      failure's reason was unrecoverable — the hover is now the way to see it next time.

- [ ] Packaging: engine runs via the transcriber venv (/Users/stage/dev/transcriber/.venv, or

- [ ] Czech on a 75-min tape ~25-30 min (Parakeet ~2 min) — no in-UI ETA; acceptable for now.
